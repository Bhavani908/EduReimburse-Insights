# 🎓 EduReimburse-Insights

A **Power BI Dashboard** that analyzes **Student Fees Reimbursement** data to uncover insights about how financial support impacts students, families, and institutions.  

## 📊 Dashboard Highlights
- **Total Reimbursement**: 8M  
- **Average Reimbursement per Student**: 40.55K  
- **Total Students**: 200  
- **Average Family Income**: 0.14M  

### 🔹 Key Insights
- District-wise reimbursement distribution  
- Caste category share (EBC, SC, ST, BC, OC)  
- Course-wise and top colleges analysis  
- Gender-wise distribution of reimbursements  
- Year-over-year reimbursement trends  

### ✨ Features
- Interactive filters: Course Type, Caste Category, Gender, Academic Year, Income Range  
- Combination of visuals: bar charts, pie charts, tree maps, and line charts  
- User-friendly and storytelling-based design  

## 🚀 Skills Used

- Data Visualization & Storytelling
